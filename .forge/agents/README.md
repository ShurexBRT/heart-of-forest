# Heart of Forest agent team

Repository-local execution team: Planner -> Builder -> Reviewer -> QA -> Runtime -> Release.

Product direction is defined and feature scope is frozen. The Golden Slice is the quality benchmark. Agents must improve combat/readability, memorable region/enemy/boss identity, restoration payoff, recognizable UI/UX, or stability/accessibility/save/performance quality — not add random scope.

All agents read `AGENTS.md`, `.forge/project.json`, `.forge/agent-api.md`, the README/Golden Slice rules, and the Forge ticket first.
